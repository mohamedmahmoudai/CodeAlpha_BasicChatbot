# CodeAlpha - Basic Chatbot 🤖

A rule-based command-line chatbot built in Python for the **CodeAlpha Internship Program**.

## 📌 Project Overview
This project demonstrates a simple conversational agent that interacts with users by processing text input and generating predefined responses based on keyword matching.

## ✨ Features
- **Rule-Based Matching:** Detects user intents using string pattern matching.
- **Input Sanitization:** Automatically handles uppercase letters and whitespace.
- **Interactive Conversation Loop:** Keeps the chat active until an exit command (`bye` or `exit`) is given.

## 🛠️ Concepts Used
- Conditional logic (`if-elif-else`)
- Functions & Modular Code
- Dictionaries & String Manipulation
- Control Flow (`while` loops)
